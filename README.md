# Flood Fill

Поле 10 на 10, каждая ячейка случайного цвета (красная/синяя). При клике по ячейке перекрашиваем в противоположный цвет всю
связную область смежных ячеек исходного цвета (по горизонтали/вертикали, без
диагоналей).

**Demo:** https://greyhound87.github.io/flood-fill/

## Стек

- Vite
- React 19
- TypeScript
- Three.js
- Biome
